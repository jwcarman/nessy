# Notebook Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Notebook — model-gated memory: named durable notes written via `remember`/`recall`/`forget` tools, with an always-injected index and bodies read on demand — plus JDBC durability, TCK coverage, and the chat-cli demo.

**Architecture:** `SubjectId` joins `api.conversation` (first non-conversation key); `spi.notebook` holds the `Notebook` SPI + `NotebookTools` (three tools + index transformer); `JdbcNotebook` uses the summary-store race-recovery upsert (concurrent writers are real here); contract in the TCK. Zero new dependencies.

**Tech Stack:** Java 21+, JUnit 5 + AssertJ, Testcontainers (vendor-tagged).

**Spec:** `docs/superpowers/specs/2026-08-15-notebook-design.md` — §2-§5 carry exact interfaces, SQL, and the injected block format. The spec is the authority; every task reads it first.

## Global Constraints

- House rules: no suppressions, no star imports, no mocking libraries, prose snake_case tests, S5778 (one throwing invocation per assertion lambda — hoist construction), S5841, no System.out.
- TCK contract methods are PUBLIC `@Test` (cross-package @Nested discovery — the documented trap).
- All SQL complete constants; batch/upsert patterns follow the named sibling classes exactly.
- Javadoc on every public member; fully-qualified `{@link}` for non-imported targets; reactor `./mvnw -q javadoc:javadoc` green before each commit.
- Full offline `./mvnw -q clean verify` green at every task boundary (no Docker, no network, no API key).
- Formatters before every commit; trailer `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`. Never push (controller pushes).
- Wire records live in NotebookTools (`RememberNote`/`RecallNote`/`ForgetNote`); the SPI records stay annotation-free.
