> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the fully generic durable-computation primitive (`nessy-durable`), the agent-side resumption handler, the parked-call policy seam, the approval desk — and prove it with a narrated demo where a parked turn survives instance death and resumes on a freshly built agent.

**Architecture:** `nessy-durable` is a new zero-dependency module: slots with one PENDING→terminal flip, atomic await, opaque continuations, and a dispatcher — it knows nothing about agents. `nessy-agent` contributes one continuation handler (`RESUME_SCOPE`), a `ParkedCallPolicy` seam on the existing tool executor (loud-failure stays the default), a `DurableParkedCallPolicy`, and an `ApprovalDesk`. `nessy-core` untouched.

**Tech Stack:** Java 25, Maven, JUnit 5, AssertJ, Jackson (agent side only — the primitive's continuation data is an opaque String). No mocking libraries.

**Spec:** `docs/superpowers/specs/2026-08-20-durable-computation.md` (the preamble's rulings bind, especially: two-armed model, generic continuations, layered exactly-once, deterministic identity) and `docs/superpowers/specs/2026-08-18-agent-as-scope-design.md` §4.3.

## Plan-level design decisions (deliberate — do not "fix")

1. **The primitive is non-generic** (`Outcome.Success(Object value)`, no `<T>`, no `DurableComputation<T>` record — the `ComputationId` suffices). The doc's generics require unchecked casts from a heterogeneous store, and `@SuppressWarnings` is banned; consumers make *checked* casts (`ToolResult` instanceof) at the boundary. Generics return if a second value type ever demands them.
2. **Deterministic identity is the caller's duty**: `create(ComputationId)` is get-or-create (returns whether it created), and the tool slot id is `"tool:" + type + ":" + id + ":" + callId` — so a recovery re-fire finds the slot and re-awaits idempotently (spec ruling 4).
3. **Prompt delivery is complete-then-fire in the completing door** (`ApprovalDesk`), at-least-once; a crash between flip and fire is covered by the lazy re-drive floor (re-fired `ExecuteTool` → policy → `await` → `AlreadyCompleted`). The transactional outbox is the Plan-5 upgrade, not built here.
4. **`ParkedCallPolicy` is a constructor seam on the existing `RegistryToolCallExecutor`** — the 4-arg constructor keeps today's loud-failure behavior verbatim; the 5-arg overload injects the policy. A suspended call delivers NOTHING and narrates NOTHING (parking is invisible — the `ToolCallParked` deletion ruling).
5. **`AgentBinder` is a new SPI in the flat `org.jwcarman.nessy.agent` package** (`void deliver(AgentType, AgentId, AgentEvent)`) — hosts implement it (the demo's binder builds a fresh `DefaultAgent` per delivery, which IS the out-of-band-bind demonstration). Package-private `DefaultAgent.deliver` stays package-private; binders live in-package.
6. **Desk expiry is NOT in this plan** — deadlines ride Plan 5 with the sweep and outbox. The `ApprovalDesk` refuses unknown tokens and already-decided slots loudly.
7. **`AgentType` finally enters the code** (it existed since Plan 1) as part of the scope coordinate in continuations and slot ids.

```java
package org.jwcarman.nessy.durable;

import java.util.ArrayList;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Objects;
import java.util.Optional;
import java.util.Set;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.ConcurrentMap;

/**
 * The reference in-memory backend. Each slot's monitor is the row lock of the SQL reference
 * (durable spec §20-21): await and complete serialize on it, so the §12 contract holds — either
 * the outcome is returned, or the continuation is registered before completion can proceed.
 */
public final class InMemoryDurableComputationBackend implements DurableComputationBackend {

  private static final class Slot {
    private ComputationStatus status = ComputationStatus.PENDING;
    private Outcome outcome;
    private final Set<Continuation> continuations = new LinkedHashSet<>();
  }

  private final ConcurrentMap<ComputationId, Slot> slots = new ConcurrentHashMap<>();

  @Override
  public CreateResult create(ComputationId id) {
    Objects.requireNonNull(id, "id must not be null");
    Slot fresh = new Slot();
    Slot prior = slots.putIfAbsent(id, fresh);
    return new CreateResult(id, prior == null);
  }

  @Override
  public AwaitResult await(ComputationId id, Continuation continuation) {
    Objects.requireNonNull(continuation, "continuation must not be null");
    Slot slot = required(id);
    synchronized (slot) {
      if (slot.status != ComputationStatus.PENDING) {
        return new AwaitResult.AlreadyCompleted(slot.outcome);
      }
      slot.continuations.add(continuation);
      return new AwaitResult.Registered();
    }
  }

  @Override
  public CompletionResult complete(ComputationId id, Outcome outcome) {
    Objects.requireNonNull(outcome, "outcome must not be null");
    Slot slot = required(id);
    synchronized (slot) {
      if (slot.status != ComputationStatus.PENDING) {
        return CompletionResult.ALREADY_TERMINAL;
      }
      slot.status = statusOf(outcome);
      slot.outcome = outcome;
      return CompletionResult.COMPLETED;
    }
  }

  @Override
  public Optional<ComputationStatus> status(ComputationId id) {
    Objects.requireNonNull(id, "id must not be null");
    Slot slot = slots.get(id);
    if (slot == null) {
      return Optional.empty();
    }
    synchronized (slot) {
      return Optional.of(slot.status);
    }
  }

  @Override
  public List<Continuation> continuationsOf(ComputationId id) {
    Slot slot = required(id);
    synchronized (slot) {
      return List.copyOf(new ArrayList<>(slot.continuations));
    }
  }

  private Slot required(ComputationId id) {
    Objects.requireNonNull(id, "id must not be null");
    Slot slot = slots.get(id);
    if (slot == null) {
      throw new IllegalArgumentException("unknown computation: " + id.value());
    }
    return slot;
  }

  private static ComputationStatus statusOf(Outcome outcome) {
    return switch (outcome) {
      case Outcome.Success ignored -> ComputationStatus.SUCCEEDED;
      case Outcome.Failure ignored -> ComputationStatus.FAILED;
      case Outcome.Cancelled ignored -> ComputationStatus.CANCELLED;
    };
  }
}
```

```java
class DurableParkDemo {

  record ApprovalInput(String action) {}

  static final class RiskyTool implements Tool<ApprovalInput> {
    // name "restart_prod", parks: return Awaited.parked(new ParkToken("tok-demo-1"));
  }

  @Test
  void aParkedTurnSurvivesInstanceDeathAndResumesOnAFreshAgent() {
    // shared, durable world: memory, store, backend, dispatcher, desk, pump, provider
    var pump = new PumpedExecutor();
    var memory = new VerbatimMemory();
    var store = new InMemoryAgentStateStore();
    var backend = new InMemoryDurableComputationBackend();
    var dispatcher = new ContinuationDispatcher();
    var desk = new ApprovalDesk(backend, dispatcher);
    var type = AgentType.of("approver");
    var id = AgentId.of("demo");
    var call = /* ToolCall the model will emit: id "c1", name "restart_prod", args {"action":"restart"} */;
    var provider = new ScriptedModelProvider(List.of(
        List.of(new ModelEvent.ToolUseEmitted(call, null)),
        List.of(new ModelEvent.TextChunk("Restarted. All good."))));

    // agentFactory: builds a FRESH DefaultAgent over the shared world — instances are disposable
    Supplier<DefaultAgent<String>> agentFactory = () -> new DefaultAgent<>(new AgentWiring<>(
        memory, store, backlog, renderer,
        new ProviderModelCallExecutor(provider, TestSettings.settings(),
            ToolRegistry.of(new RiskyTool()), memory, narrator, pump),
        new RegistryToolCallExecutor(ToolRegistry.of(new RiskyTool()), id, narrator, pump,
            new DurableParkedCallPolicy(backend, desk, type, id)),
        observerWithPrintlns, false, Duration.ofMinutes(5), Clock.systemUTC()));

    dispatcher.register(ScopeResumption.TYPE,
        new ScopeResumption((t, i, event) -> agentFactory.get().deliver(event)));  // fresh instance per delivery!

    System.out.println("== turn begins ==");
    agentFactory.get().observe("please restart prod");
    pump.pumpUntilQuiet();
    System.out.println("phase after park: " + store.load().phase().getClass().getSimpleName());
    // assert: AwaitingTools, backend PENDING, desk holds tok-demo-1, NOTHING delivered

    System.out.println("== the instance is garbage now; hours pass; any node may answer ==");
    desk.approve(new ParkToken("tok-demo-1"), ToolResult.ok("approved by jcarman"));
    pump.pumpUntilQuiet();

    System.out.println("final phase: " + store.load().phase());
    // assert: Idle; slot SUCCEEDED; memory = user / assistant(toolUse) /
    //   user(toolResults containing "approved by jcarman") / assistant("Restarted. All good.")
    memory.recall().messages().forEach(m -> System.out.println("  " + m.role() + ": "
        + m.content().stream().map(b -> b.getClass().getSimpleName()).toList()));
  }
}
```
