# Storage Kernel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Land `ScopedStore` (documents + journal + batch), rebase every store on kernel recipes, and extract intent into its own `nessy-intent` jar.

**Architecture:** One storage SPI in `nessy-spi` with an in-memory reference substrate beside it; recipes in `nessy-agent` implement the surviving domain vocabulary (`AgentStateStore`, `Memory`, `Backlog<String>`, `DurableComputationBackend`) over the kernel; a persistence codec (nessy-owned Jackson binding, zero annotations) renders the message/phase vocabulary and the closed outcome vocabulary to JSON; the `Nessy` builders gain one `.store(ScopedStore)` seam and the five bespoke in-memory substrates die; intent becomes an optional feature jar. The scope engine, phases, desks, dispatcher, and doors are untouched.

**Spec:** `docs/superpowers/specs/2026-08-21-scoped-store-design.md` (binding), which supersedes the storage mechanics of `2026-08-20-durable-computation.md` — whose semantic law (one flip, atomic await, ruling 6, continuation dedup) the recipes must prove. Outbox and summary are SPECIFIED, NOT BUILT (spec §13).

## Global Constraints

- `./mvnw -q clean verify` green with no API key and no network — final gate, ONCE per task; iterate with `./mvnw -q -pl <module> -am test` (build economics per CLAUDE.md). Never two Mavens in one worktree.
- Before every commit: `./mvnw license:format -Plicense && ./mvnw spotless:apply`.
- House law: no mocking libraries; no `@SuppressWarnings`; no star imports; prose (camelCase) test names; S5778 one-throwing-call lambdas; S5841 assert-non-empty-before-match; sealed-grammar etiquette (grammar members nested in the sealed type).
- Zero Jackson annotations on domain types — all binding is nessy-owned codec code (house law, precedent: `SealedInputs`/`Schemas`).
- Design-authority rule: any concept not named in this plan or the spec stops the task and asks the controller.
- Kernel semantics are spec §4 verbatim: CAS law (0-sentinel create, `ConflictException` on any miss), journal law (seq from 1, create-only, no destructive ops), batch law (all-or-nothing, small), `keys` law (ascending, `limit >= 1`), opacity (payloads are opaque non-null strings), thread safety.
- Reserved kinds and layouts are spec §5; recipes are spec §6; the closed outcome vocabulary (`ToolResult`, `Decision`, reject others at the door) is spec §7.
- New published module (`nessy-intent`) must pass `mvn -P release -DskipTests -Dgpg.skip=true verify` (javadoc) before its final commit; BOM entry; license headers.

## Tasks

### Task 1: The kernel — `ScopedStore` + `InMemoryScopedStore` (nessy-spi)
**Files:** Create `nessy-spi/src/main/java/org/jwcarman/nessy/spi/store/ScopedStore.java` (interface exactly as spec §3: `read`, `write`, `delete`, `keys(kind, limit)`, `append`, `entries`, `batch`, with nested `Document(payload, version, updatedAt)`, `Entry(seq, payload, appendedAt)`, sealed `Op` with nested records `WriteDocument`/`DeleteDocument`/`AppendEntry`), `ConflictException.java` (final, RuntimeException, carries a message naming kind/key and expected-vs-actual), `InMemoryScopedStore.java` (public final; one lock — a single synchronized guard or `ConcurrentHashMap` with per-entry CAS is fine, but `batch` MUST be atomic and isolated: validate every op's expectation, then apply all, under one mutual exclusion; constructor takes `Clock`, no-arg defaults to `Clock.systemUTC()`).
**Produces:** the kernel contract every later task consumes. Semantics: spec §4, all seven laws. `keys` ascending lexicographic, at most `limit`, `limit < 1` → `IllegalArgumentException`. `entries(kind, key, fromSeq)` ascending, inclusive, empty for unknown key. Null kind/key/payload → NPE with message.
**Tests** (`nessy-spi/src/test/java/.../store/InMemoryScopedStoreTest.java`, prose names): create at version 1; CAS increments; stale write/delete/create-when-present each throw `ConflictException`; delete requires match; read absent = empty; keys order + limit + IAE; append at 1, at head+1, conflict on occupied seq, conflict on gap is NOT required (only exact-seq create); entries from-seq slicing; batch mixed-shape success applies all; batch with one stale op applies NOTHING (verify both shapes untouched); updatedAt/appendedAt come from the injected fixed Clock; a small concurrency race (two threads CAS the same doc, exactly one wins per round).
**Commit:** `feat: the storage kernel — two shapes, one batch, seven methods`

### Task 2: The persistence codec (nessy-agent)
**Files:** Create `nessy-agent/src/main/java/org/jwcarman/nessy/agent/codec/MessageCodec.java` and `StateCodec.java` (both public final, static methods, private ctor; javadoc marks them internal machinery, not API vocabulary).
**Interfaces:** `MessageCodec.toJson(Message)`, `MessageCodec.message(String)`, `MessageCodec.toJson(Context)`, `MessageCodec.context(String)`; `StateCodec.toJson(Phase)`, `StateCodec.phase(String)`.
**Binding rules:** discriminator field `"type"` on every polymorphic node, mirroring the `Schemas`/`SealedInputs` kebab-or-simple-name convention — pick the record simple name (`TextBlock` → `"text"`, `ImageBlock` → `"image"`, `ThinkingBlock` → `"thinking"`, `RedactedThinkingBlock` → `"redacted-thinking"`, `ToolUseBlock` → `"tool-use"`, `ToolResultBlock` → `"tool-result"`; phases `"idle"`, `"awaiting-model"`, `"awaiting-tools"`). Cover the full vocabulary: `Message(role, content blocks)`, `ToolCall`, and the three phases (`AwaitingTools` carries `assistantTurn` message, `pending` set, `gathered` tool-result blocks). Tolerant reads: unknown JSON fields ignored; absent optional fields defaulted; malformed JSON or unknown discriminator → `IllegalArgumentException` naming the offense. Jackson `ObjectMapper` held privately; no annotations on domain types.
**Tests:** round-trip every content-block type, both roles, a full `Context`, each phase including a populated `AwaitingTools` (its compact-constructor invariants must survive the round trip); unknown-field tolerance (parse JSON with an extra field); unknown discriminator and malformed JSON rejection (S5778: one throwing call per lambda).
**Commit:** `feat: the vocabulary learns to be written down — message and phase codecs`

### Task 3: State, memory, and backlog recipes (nessy-agent)
**Files:** Create `org/jwcarman/nessy/agent/store/StoredAgentStateStore.java`, `org/jwcarman/nessy/agent/memory/StoredMemory.java`, `org/jwcarman/nessy/agent/backlog/StoredBacklog.java`. Do NOT delete the old substrates yet (Task 5 rewires and deletes).
**Interfaces:** `StoredAgentStateStore(ScopedStore store, String agentId, Clock clock) implements AgentStateStore` — kind `state`; the document version IS the scope version: `load()` absent → `State.initial()` else `new State(StateCodec.phase(payload), doc.version())`; `save(state)` → `write(…, expectedVersion = state.version())`, catching `ConflictException`, re-reading, and rethrowing `StaleStateException(state.version(), actualStoredVersion)`; `lastSaved()` absent → the instant captured at construction (parity with `InMemoryAgentStateStore`), else `updatedAt`. `StoredMemory(ScopedStore store, String agentId) implements Memory` — kind `memory`, journal; `remember` appends at head+1 with re-read-and-retry on conflict; `recall` folds `entries(…, 1)` into `Context` via `MessageCodec`. `StoredBacklog(ScopedStore store, String agentId, int capacity) implements Backlog<String>` — kind `backlog`, one document holding a JSON array of strings (plain Jackson array, no codec needed); `add` full → reject exactly as `BoundedBacklog` does today (read `BoundedBacklog.add` first and mirror its behavior precisely); `add`/`poll` are read-mutate-CAS-retry loops; absent doc = empty queue; poll on empty → `Optional.empty()`.
**Tests:** per recipe, prose-named: state round-trips phase and version through the kernel, stale save throws `StaleStateException` carrying both versions, never-saved `lastSaved` is construction instant (fixed Clock); memory remembers/recalls in order across two `StoredMemory` instances sharing one kernel (proving durability is in the store, not the object); a conflict-retry test (pre-seed the journal, then remember); backlog FIFO, bounded rejection at capacity, empty poll, and two views over one kernel share the queue.
**Commit:** `feat: state, memory, and backlog become recipes over the kernel`

### Task 4: Computations become a recipe — `StoredComputations` (nessy-agent)
**Files:** Create `org/jwcarman/nessy/agent/durable/StoredComputations.java` and `org/jwcarman/nessy/agent/durable/OutcomeCodec.java` (public final, internal-machinery javadoc). Do NOT delete `InMemoryDurableComputationBackend` yet.
**Interfaces:** `StoredComputations(ScopedStore store) implements DurableComputationBackend` — kind `computation`, key = `id.value()`, one document `{status, outcome?, continuations[]}`. `OutcomeCodec` renders the closed vocabulary (spec §7): `Success(ToolResult)`, `Success(Decision)` with a type discriminator, plus `Failure(message)` and `Cancelled(reason)`; `complete()` with a `Success` payload of any other type → `IllegalArgumentException` at the door, nothing written. Continuations serialize as `{type, data}` pairs (already strings).
**Semantics to prove (the durable spec's law, now over CAS):** `create` = `write(…, 0)`, conflict → read existing, `created=false`; `await` = read; terminal → outcome arm; else CAS-append continuation with set semantics (equal continuation twice is one registration), conflict → retry; `complete` = read; terminal → `ALREADY_TERMINAL`; absent → create already-terminal (ruling 6); else CAS flip, conflict → retry (and re-evaluate terminality); `status` absent → empty; `continuationsOf` = snapshot list.
**Tests:** port the semantic assertions from `InMemoryDurableComputationBackend`'s test suite to run against `StoredComputations` over an `InMemoryScopedStore` (read that suite first; keep its prose names where they still tell the truth), PLUS: one-flip under racing completes (two threads, one `COMPLETED`, one `ALREADY_TERMINAL`); complete-unknown-id creates terminal and a later `await` gets `AlreadyCompleted`; duplicate continuation registers once; rejected foreign payload leaves the document absent; outcomes round-trip through JSON (a `ToolResult` and a `Decision` come back equal).
**Commit:** `feat: durable computations are a recipe — the backend SPI retires to vocabulary`

### Task 5: One store to build on — builder rework and the six deaths
**Files:** Modify `org/jwcarman/nessy/agent/host/Nessy.java` (both builders); delete `InMemoryStateSubstrate`, `InMemoryMemorySubstrate`, `InMemoryBacklogSubstrate`, `InMemoryAgentStateStore`, `BoundedBacklog`, and `nessy-durable`'s `InMemoryDurableComputationBackend`; migrate every test/example that constructed them.
**Interfaces:** `AutonomousBuilder.store(ScopedStore)` — the one storage seam, default `new InMemoryScopedStore()`; defaults derived from it in `build()`: `memoryFactory` default `id -> new StoredMemory(store, id)` (the `.memoryFactory(…)` override seam survives — floor, not ceiling), state factory becomes `id -> new StoredAgentStateStore(store, id, clock)` and the `storeFactory(…)` builder method DIES, backlog factory `id -> new StoredBacklog(store, id, backlogCapacity)`, `backend` default `new StoredComputations(store)` (`.backend(…)` override survives for foreign engines). CliBuilder: same store-backed defaults, `StalenessPolicy.never()` and AWAITABLE-limited registry unchanged. If `BoundedBacklog` has consumers beyond the substrate/default path, keep it and delete only the substrate — check with grep first and record the call in the report.
**Tests:** builder tests updated to the new seams; a new prose test proving two deliveries to the same agent through `AutonomousHost` share one `ScopedStore` (post → reply persisted in the store's `memory` journal — observable via a second binding); `NoPublicBuildersTest` and zone tests still green; whole-reactor `clean verify` (this is the wiring task — full gate earns its keep here).
**Commit:** `feat: one store to build on — the bespoke substrates die`
