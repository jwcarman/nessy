### Task 1: The kernel — two variants, their hooks, the emission contract (HIGH RISK — Opus review)

**Files:** `nessy-core`: `api/turn/TurnEvent.java` (+2 variants), `api/turn/TurnObserverAdapter.java` + `TurnObserverBuilder.java` (+2 hooks each), `api/turn/TurnObserver.java` (the `logging` factory, BUILT ON `builder()`), `internal/ConversationLoop.java` (emission points); tests: `ConversationLoopTest` emission-contract cases, `TurnObserverBuilderTest`/adapter tests extended, a `TurnObserverLoggingTest`.

**Binding semantics (spec §2 — the reviewer holds the diff to these):**
- `record AssistantSaid(Message message)` — emitted once per model response the fold absorbs, INCLUDING tool-use-only responses; emitted at the same beat the `ModelResponded` fact is emitted (inside the loop's per-fact cycle, so the existing at-least-once narration rule applies; javadoc says so and cross-references the roster's dedupe guidance).
- `record TurnEnded(ConversationStatus status, String failureReason)` — `failureReason` null unless FAILED (compact constructor requires status non-null; requires failureReason null iff status != FAILED? NO — keep it simple and honest: non-null only meaningful for FAILED, javadoc'd, no cross-field validation beyond `Objects.requireNonNull(status)`). Emitted EXACTLY ONCE per observed segment at every exit: `driveOnce`'s settled return (COMPLETE/FAILED/IDLE-quiescent) and the parked outcome — **after the final save lands** (`ToolCallParked`'s post-save discipline; an ending that never committed is never narrated). The park path emits `ToolCallParked` THEN `TurnEnded(PARKED, null)`. The exception path (save-then-rethrow in the finally) emits NO ending — a caller whose `tell` throws did not get a story ending, they got the exception.
- `TurnObserver.logging(Logger logger, String prefix)`: builder-composed; says-line per `AssistantSaid` with text blocks joined (skip when blank), tool requested/completed/parked lines (park includes token), `TurnEnded` → INFO `"{prefix} ends: {status}"` plus WARN with failureReason when FAILED.
- Emission-contract tests: AssistantSaid count == model responses (incl. a tool-use-only response); TurnEnded exactly once for COMPLETE, FAILED (reason carried), PARKED (after ToolCallParked); a fenced-save loser narrates no ending (extend the existing stale-save loop test); multi-call segment (tool loop) = N AssistantSaid, 1 TurnEnded.
- Commit: `feat: the turn finishes its sentences — AssistantSaid and TurnEnded join the story`
